# Lead Hunter — Поиск лидов на ремонт квартир в Telegram

Автоматическая система поиска потенциальных клиентов на ремонт квартир в Telegram-чатах новостроек Санкт-Петербурга.

## Архитектура

```

│  Telethon    │────▶│  AI Analyzer │────▶│ PostgreSQL│
│  Monitor     │     │  (OpenAI)    │     │           │
└─────────────┘     └──────────────┘     └─────┬────┘
                                                │
┌─────────────┐     ┌──────────────┐           │

└─────────────┘     └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │ Telegram Bot │
                    │ (уведомления)│
                    └──────────────┘
```

## Быстрый старт

### 1. Получите API ключи

| Сервис | Где получить |
|--------|-------------|
| Telegram API | https://my.telegram.org |
| Bot Token | @BotFather в Telegram |
| OpenAI API | https://platform.openai.com/api-keys |

### 2. Настройте переменные окружения

```bash
cp .env.example .env
# Заполните .env своими ключами
```

### 3. Запустите

```bash
docker-compose up -d
```

### 4. Откройте

- **Веб-панель:** http://localhost:8000
- **Telegram:** бот пришлёт уведомления о лидах

## Первый запуск

1. При первом запуске Telethon запросит номер телефона и код — это одноразовая авторизация
2. Сессия сохранится в папку `sessions/`
3. Добавьте чаты через веб-панель (Settings) или в `.env`

## Добавление чатов

### Через веб-панель
1. Откройте http://localhost:8000/settings
2. Добавьте @username чата

### Через .env
```
MONITORED_CHATS=@chat1,@chat2,@chat3
```

## Ключевые слова для поиска

Система отслеживает сообщения с ключевыми словами:
- ремонт, бригада, отделка, мастера
- ремонт под ключ, ищу бригаду
- получили ключи, приемка квартиры
- смета, дизайн проект, электрика, сантехника

## AI-анализ

Каждое сообщение проходит AI-анализ и получает оценку:
- **Lead Score 90-100:** горячий лид
- **Lead Score 80-89:** тёплый лид
- **Lead Score 70-79:** потенциальный лид
- **Below 70:** не является лидом
